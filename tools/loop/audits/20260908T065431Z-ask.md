## Prompt

An Android game declares no permissions at all in its manifest — no INTERNET, no storage, no location, no advertising ID. All assets ship inside the APK and it works in aeroplane mode. The developer wants to answer Google Play's Data Safety form with 'no data collected, no data shared'. Name the most likely way that declaration could still be wrong.

## Auditor response

The declaration is likely incorrect due to **manifest merger**. While the developer's source `AndroidManifest.xml` may contain no permissions, the Android build process automatically merges permissions declared by any third-party SDKs included in the project's dependencies into the final APK. This can silently introduce permissions like `INTERNET`, enabling data collection and transmission that the developer did not explicitly request. This bites whenever the project includes dependencies (such as analytics, crash reporting, or advertising libraries) that declare permissions in their own manifests.
