## Prompt

A deterministic game runs its simulation in integer fixed-point (Q16.16) TypeScript on phones, and the same algorithm ported to a WGSL compute shader on desktop GPUs. CI proves the two bit-identical on a software Vulkan device. Both are integer-only: no floating point anywhere in the simulation. Name the single most likely way a phone run and a desktop run of the same seed and same inputs could still produce different results.

## Auditor response

Divergent integer overflow semantics. In TypeScript, standard arithmetic operators (`+`, `-`, `*`) operate on 64-bit floats, which do not wrap at 32 bits but instead maintain integer precision up to $2^{53}-1$. In contrast, WGSL integer types (`i32`, `u32`) implement fixed-width two's complement wrap-around. This bites whenever an intermediate calculation exceeds the 32-bit signed integer range and the TypeScript code relies on standard arithmetic instead of explicitly forcing 32-bit wrapping (e.g., via `| 0` or `Math.imul`).
