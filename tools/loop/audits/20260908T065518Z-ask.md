## Prompt

A game verifies scores by recording only a seed and one player input per tick, then recomputing the result from scratch. No positions are recorded, so the claim is that forging a high score requires actually playing the game. Assume the recording and the verifier are both correct. Name the strongest remaining way someone could obtain a top score without playing well.

## Auditor response

Input scripting (or Tool-Assisted Speedrunning) is the strongest method. An attacker can use an offline simulation to find a sequence of inputs that maximizes the score for a specific seed, then feed that sequence to the recorder. This bites if the game's mechanics are deterministic and the input-to-score mapping can be computationally solved or brute-forced offline.
