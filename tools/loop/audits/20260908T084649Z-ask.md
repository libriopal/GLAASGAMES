## Prompt

A competitive game shows every player a simplified 2D view that summarises a richer hidden simulation state. The full state is deterministic and the client computes it locally in order to draw the view. Players compete for ranking, and matches are verified by replaying recorded inputs. Name the single strongest exploit this design permits, and what it would take to close it.

## Auditor response

Information leakage (Map Hacking). This bites because the client computes the full simulation state locally, meaning all "hidden" data—such as enemy positions in the fog of war or unrevealed cooldowns—is resident in the client's memory. To close it, you must implement server-side interest management (fog of war pruning), where the server only transmits state updates for entities within the player's observable scope, ensuring the client's local simulation is intentionally incomplete.
