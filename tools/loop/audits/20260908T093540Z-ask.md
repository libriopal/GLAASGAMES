## Prompt

A game hides information using hash commit-reveal: the seed is committed before the round, revealed after, and the player verifies. The game runs offline on the player's own device. What is the strongest attack? 9000

## Auditor response

The strongest attack is local code or memory manipulation (e.g., binary patching or memory editing). Because the game runs offline on the player's own device, the player has total control over the execution environment and can bypass the commit-reveal mechanism entirely by modifying the game logic to force a winning outcome regardless of the seed. This bites whenever the player has administrative or root access to the device running the game.
