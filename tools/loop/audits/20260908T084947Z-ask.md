## Prompt

A design proposes replacing a 4D game view with a flat 2D map, and defends it with this claim: the view need not be state-complete, only DECISION-COMPLETE — for any two world states whose optimal action differs, the view must render them distinguishably. They plan to verify it by sampling state pairs, computing the optimal action by bounded search, and asserting the renders differ. Name the strongest reason this verification could pass while the real game still misleads players.

## Auditor response

The verification is vulnerable to **horizon effects** caused by the bounded search. The test will pass if the 2D map distinguishes states based on the *locally* optimal actions identified within the search depth, even if those states require different *globally* optimal actions that the map fails to distinguish. This occurs when the information necessary to differentiate true optimal actions is omitted from the 2D view.

**Condition:** The game's optimal strategy depends on state features or consequences that manifest only beyond the search's lookahead horizon.
